Spring Notes 🌱 Introduction to Spring Spring is a lightweight, open‑source framework for building enterprise Java applications.

It provides infrastructure support so developers can focus on business logic instead of boilerplate code.

It promotes loose coupling, modularity, and easier testing.

❓ Why Spring? Servlets/JSP are low‑level and require a lot of manual coding.

Spring abstracts repetitive tasks and provides a consistent programming model.

It integrates easily with other frameworks (Hibernate, JPA, Struts, etc.).

Offers modularity — you can use only what you need (Spring Core, Spring MVC, Spring AOP, etc.).

Makes applications easier to maintain and test.

🧩 What is Spring? A comprehensive framework for enterprise Java development.

Provides features like IoC (Inversion of Control), AOP (Aspect‑Oriented Programming), transaction management, and integration with ORM tools.

Supports building web applications, REST APIs, and microservices.

Forms the foundation for Spring Boot, which simplifies configuration and deployment.

🏭 Key Modules Spring Core → Fundamental features, IoC container.

Spring Context → Framework‑style access to objects (ApplicationContext).

Spring AOP → Separation of cross‑cutting concerns (logging, security, transactions).

Spring DAO/ORM → Simplifies database access and integrates with ORM tools.

Spring Web/MVC → Web application development with MVC architecture.

Spring Security → Authentication and authorization.

Spring Test → Testing support for Spring components.
